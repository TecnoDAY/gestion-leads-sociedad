# Gestión de Leads 2026 — Sociedad Actoral

Sistema integral de gestión comercial, seguimiento operativo y analítica histórica de prospectos para **Sociedad Actoral**, conectado en tiempo real a **Supabase (PostgreSQL)** y diseñado para despliegue instantáneo en **Vercel** o como archivo estático autocontenido.

---

## 🌟 Características Principales

### 1. Panel Operativo & Leads
- **Métricas Clave (KPIs):** Total de leads, citas agendadas, alumnos inscritos y tasa de conversión calculados en tiempo real.
- **Filtros Dinámicos:** Búsqueda reactiva por mes, campaña, medio de captación, estatus de gestión y buscador de texto libre (nombre o teléfono).
- **Matriz Cruzada Interactiva (Gestión vs. Campaña):** Tabla dinámica bidimensional con totales por fila/columna y filtrado interactivo al hacer clic en cualquier celda.
- **Tabla Paginada con Acciones Rápidas:**
  - Enlace directo a WhatsApp (`https://wa.me/`) con saludo personalizado.
  - Badges de color según estatus comercial (Inscrito, Agendado, Información, etc.).
  - Modal de edición rápida y registro de notas de seguimiento.
  - Modal para alta de nuevos prospectos.

### 2. Pestaña de Gráficos Históricos (2026)
- **Evolución Mensual:** Comparativa de barras y líneas (Leads captados vs. Inscripciones logradas).
- **Tendencia de Conversión:** Curva porcentual de efectividad mes a mes.
- **Rendimiento por Campaña:** Análisis comparativo de los programas con mayor demanda (Kids, Adultos, Summer Camp, Weston, etc.).
- **Canales de Entrada:** Gráfico de dona con distribución de procedencia (WhatsApp, Instagram, Lead Directo, Referidos).
- **Cierres por Asesor:** Rendimiento individual de asesores comerciales.
- **Tabla Resumen Consolidada:** Desglose cronológico mensual con hitos destacados.

## 🗄️ Esquema de la Base de Datos (`leads` en Supabase)

La tabla `leads` en Supabase utiliza la siguiente estructura exacta:

| Columna | Tipo | Descripción |
| :--- | :--- | :--- |
| `id` | `BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Identificador único |
| `Mes` | `TEXT` | Mes de captación (ej: ENERO, FEBRERO...) |
| `Fecha` | `TEXT` | Fecha del lead (ej: 1/01/2026) |
| `Nombre` | `TEXT` | Nombre del prospecto o cliente |
| `Telefono` | `TEXT` | Teléfono / WhatsApp |
| `Campaña` | `TEXT` | Programa de interés (ej: Actuacion Adultos, Kids...) |
| `Medio` | `TEXT` | Canal de entrada (Instagram, Whatsapp, Referidos...) |
| `GESTION` | `TEXT` | Estatus comercial (INSCRITO, Agendado, Información...) |
| `Ciudad` | `TEXT` | Ciudad o zona (Coral Gables, Doral, Weston...) |
| `AGENTE` | `TEXT` | Asesor asignado (Nina, Jessi, Loli, Ana...) |
| `Odoo` | `TEXT` | Registro en CRM Odoo (SI N., SI J., No...) |
| `Fecha de Atencion` | `TEXT` | Fecha de primer contacto |
| `OBSERVACIONES ` | `TEXT` | Notas de seguimiento comercial *(espacio al final)* |
| `Fecha Última Gestión ` | `TEXT` | Fecha de última interacción *(espacio al final)* |
| `ULTIMA GESTION` | `TEXT` | Canal de último seguimiento (Llamada, WhatsApp...) |
| `ULTIMO AGENTE ` | `TEXT` | Asesor de último seguimiento *(espacio al final)* |
| `LANDING` | `TEXT` | Página o formulario de captura |

## 🚀 Despliegue en Vercel

1. Haz un fork o sube este repositorio a tu cuenta de GitHub.
2. En tu panel de **Vercel** (`vercel.com`):
   - Haz clic en **"Add New Project"**.
   - Importa el repositorio `gestion-leads-sociedad`.
   - Vercel detectará automáticamente la configuración estática/Vite y desplegará `index.html`.
3. ¡Listo! Tu panel estará disponible en una URL `*.vercel.app`.

---

## 💻 Ejecución Local

Puedes abrir directamente el archivo `index.html` en cualquier navegador web moderno, o ejecutar el servidor de desarrollo Vite:

```bash
# Instalar dependencias
npm install

# Iniciar servidor local
npm run dev
```

El panel estará disponible en `http://localhost:3000`.
